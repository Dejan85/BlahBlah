## 1. Šta je BlahBlah

Social media mobilna aplikacija (Expo / React Native), hibrid **Snapchat + Instagram**.
Stanje: **Faza 0, 1 i 2 ZAVRŠENE** (T1.1–T1.9, T2.1–T2.3 gotovi); **Faza 3 u toku — T3.1–T3.7 ✅** (`lib/formatCount.ts` + `lib/blahScore.ts` — Blah Score formula `(Blahs×4)+(Followers×0.8)+Streak Bonus` + test; DB storage: `profiles.blah_score`/`blahs_sent` kolone; UI: svoj profil obračunava+upisuje skor, `formatCount(skor)` + crveni Blahs stat MyProfile 8.9; `lib/streak.ts` — kalendarski streak (tz-aware) + reset + `currentStreakDay` + rolling bunny deadline; bonus dani 8/20/28/48 single source). **T3.6 ✅: streak DB + background reset job** — kolone `profiles.streak_day`/`last_blah_at`/`streak_tz_offset` (migracija live), **pg_cron sweep `reset_lapsed_streaks()` (hourly, atomski, tz-aware)** nulira pale streak-ove serverski; slanje Blah-a (`app/blahs/new.tsx`) sad upisuje streak preko `registerBlah` **+ inkrementira `blahs_sent`** (bio nikad inkrementiran → skor sada raste); profil koristi pravi `currentStreakDay` (bonus 8/20/28/48 aktivni) + on-read lazy reset. SQL sweep je veran port granice iz `lib/streak.ts`, zakovan pinning testom (anti-drift). **T3.7 ✅: `lib/blahRecovery.ts`** — rolling recovery prozori (anchor = poslednji Blah, odvojeno od kalendarskog `streak.ts`): `safe` (0–26h) → `recoverable` (26h–39h, ponuda 13h) → `expired`; `getRecoveryStatus`/`isRecoveryAvailable`/`msUntilStreakLost`/`msUntilOfferExpires`/`isRecoveryUrgent` (urgency bunny 3h pre pada) + konstante (€1.99). **Sledeće: T3.8** (recovery popup MyProfile 8.8 + RevenueCat plaćanje €1.99).
